# Chatbot Arena Human Preference Prediction

## Project Overview
This project focuses on predicting user preferences in head-to-head battles between large language models (LLMs) in the Chatbot Arena. The goal is to build a machine learning model capable of determining which chatbot response users are likely to prefer based on a given dataset of conversations between users and chatbots. This effort is part of improving chatbot alignment with human preferences through Reinforcement Learning from Human Feedback (RLHF).

## Dataset
The dataset contains multiple conversation records where users provide prompts, and two LLMs (models A and B) generate responses. Users select the response they prefer, and the task is to predict which response will be favored.

### `train.csv`:
- `id`: Unique identifier for each conversation.
- `model_a`: The first chatbot model.
- `model_b`: The second chatbot model.
- `prompt`: The input provided by the user.
- `response_a`: Response generated by model A.
- `response_b`: Response generated by model B.
- `winner_model_a`: Binary column marking model A as the winner (1 if selected, 0 otherwise).
- `winner_model_b`: Binary column marking model B as the winner.
- `winner_tie`: Binary column marking a tie between both models.

### `test.csv`:
- `id`: Unique identifier for test set rows.
- `prompt`: The prompt provided by the user.
- `response_a`: Response from model A.
- `response_b`: Response from model B.

### `sample_submission.csv`:
- An example of the required submission format.
